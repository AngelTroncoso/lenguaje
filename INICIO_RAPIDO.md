# 🚀 Inicio Rápido - Lenguajes del Mundo Vivo

## En 3 Pasos

### 1️⃣ Instalar
```bash
cd "c:\Users\angel\OneDrive\Escritorio\lenguaje\lenguaje-app"
npm install
```

### 2️⃣ Ejecutar
```bash
npm run dev
```

### 3️⃣ Ver
Abre tu navegador en: **http://localhost:3000**

---

## 🌐 Deploy a Vercel (Opcional)

### Método 1: Interfaz Web
1. Sube el proyecto a GitHub
2. Ve a https://vercel.com
3. Importa tu repositorio
4. ¡Listo! Deploy automático

### Método 2: Terminal
```bash
npm install -g vercel
cd lenguaje-app
vercel
```
